# OWC Design Identity & Visual Language

## Brand Identity: "Professional media control surface for worship"

Not "church software." A broadcast-grade production tool that worship teams are proud to use.

---

| Element | Color | Hex | Usage |

## Visual Properties

- Corner radius: 8-12px on cards/panels
- Subtle glassmorphism on key panels (blur + 5-10% transparency)
- Soft glow on live/active elements (box-shadow with accent color)
- Smooth micro-animations (150-300ms transitions)
- Depth: panels float above background (subtle shadow or lighter bg)

## Layout Principles

1. Live outputs are HERO elements (top of screen, largest preview)
2. Slide grid is dominant workspace (center)
3. Service order is slim collapsible sidebar (left)
4. Transport bar at bottom (media player pattern)
5. Search is universal (header bar, Ctrl+K)
6. No tab switching for content — sidebar navigation drives view
7. Asymmetric: thin sidebar + wide workspace

## Key Visual Differentiators from Competition

| Them | Us |
|------|-----|
| Green accent (WorshipTools) | Electric Cyan `#00D4FF` |
| Flat dark panels | Depth + subtle glassmorphism |
| Output preview hidden at bottom | Outputs are HERO at top |
| Static layout | Smooth micro-animations |
| Tabs to switch modes | Sidebar drives navigation |
| 3 equal columns | Asymmetric layout |
| "Church software" feel | "Media production control room" feel |
