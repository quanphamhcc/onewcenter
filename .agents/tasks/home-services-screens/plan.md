## CRITICAL crash-avoidance rules (state these loudly — three prior window-open crashes)

- **Never add any `{StaticResource ...}` reference inside `OperatorWindow.xaml`.** Its new hosts (`HomePanel`, `ServicesListPanel`) use hardcoded inline brushes only (e.g. `Background="#0F1117"`). The rich themed UI lives in the two UserControls, which DO merge `OwcDesignSystem.xaml` and may use its keyed styles.
- **Only the verified `*Brush` key names exist.** Every `{StaticResource}` in the new UserControls and the two new styles must use `OwcTextPrimaryBrush`, `OwcTextSecondaryBrush`, `OwcTextMutedBrush`, `OwcPanelBrush`, `OwcSurfaceBrush`, `OwcSurfaceHoverBrush`, `OwcBorderBrush`, `OwcAccentBrush`, `OwcBackgroundBrush`. A wrong key throws at load — the exact crash class to avoid.
- **Any ComboBox uses `Style="{StaticResource OwcDarkComboBox}"`** (readable dark). Never the default white template. NO implicit/keyless styles anywhere — every new style is keyed and applied explicitly.
- **FORBIDDEN / untouched:** chord rendering, `LoadStandaloneSong`, F2/F3 `LoadSong`, the ComboBox theme definitions (`OwcDarkComboBox` et al. — consume, never modify), sidebar item-click (`ServiceOrderList_SelectionChanged` → `GoToItem`), `LoadAllAsync`, and the per-item dialogs' internals.
